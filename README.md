# Murtadha Najem Portfolio

A clean, responsive, single-page portfolio for a Data Analyst and AI Engineer. It is built with plain HTML, CSS, and minimal JavaScript, so it can be hosted directly on GitHub Pages.

## Files

- `index.html` - page structure, content, links, and sections
- `style.css` - visual system, responsive layout, dark mode, RTL support, and reusable components
- `script.js` - mobile navigation, project modals, accordions, language toggle, dark mode, and dynamic footer year
- `assets/docs/` - CV, reports, and project documents
- `assets/images/` - site icon and image assets

## Sections

- Hero
- About
- Featured Projects
- Learning & Practice Projects
- Edge AI & IoT Projects
- Workflow Automation Tools
- Side Projects & Personal Tools
- Community & Volunteering
- Skills
- Credentials
- Contact
- Footer

## Features

- Responsive mobile-first layout
- English / Arabic language toggle
- Light / dark theme toggle
- Collapsible secondary project sections
- Project detail modals
- GitHub Pages compatible

## GitHub Pages

Push these files to a GitHub repository, then enable GitHub Pages from the repository settings. Use the root of the main branch as the publishing source.
